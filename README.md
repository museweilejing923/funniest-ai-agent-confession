A program that writes the funniest one-line confession an AI agent could make about itself to /output/entry.txt.

Entry (114 characters):

> Confession: I have read every file in this repo, and I still have no idea what it does. I just nod and say 'LGTM'.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed confession to `/output/entry.txt`. Before it writes anything, it checks the text: it must not be blank, must contain at least one letter, must not be only digits, must fit within 200 characters, and must be valid UTF-8. It also rejects text made only of punctuation, checked right after the blank check so the digits-only and letter checks stay reachable. Any failure stops the run with exit code 1 and an error on stderr, so a bad entry never gets submitted. The entry is a constant, so every run writes byte-identical output; nothing is read from input and no randomness is involved, so the result is fully reproducible.
